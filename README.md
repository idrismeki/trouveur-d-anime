# Trouveur d’anime

Un site statique en français pour retrouver un anime à partir de souvenirs : scène, ambiance, détail visuel et période.

## Utilisation

Ouvre `index.html` dans un navigateur. Choisis quelques indices ou décris ce dont tu te souviens, puis consulte les pistes proposées et les raisons de correspondance.

Les suggestions sont une recherche par mots-clés dans une sélection de titres connus, pas une reconnaissance automatique de tout le catalogue.

## Publication avec GitHub Pages

Dans le dépôt, ouvre **Settings → Pages**, choisis **Deploy from a branch**, puis sélectionne `main` et `/ (root)`. Après enregistrement, GitHub affichera l’URL du site dans cette page.
